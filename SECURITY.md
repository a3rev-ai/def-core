# Security Policy

This repository is def-core, the Digital Employees WordPress plugin.

## Supported versions

The latest release on GitHub.

## Reporting a vulnerability

Email **security@a3rev.com**. For data-protection matters, such as a data request, email **hello@widrow.ai**.

Please include:

- the affected component and plugin version
- steps to reproduce
- the impact you expect

Please keep the report private until it is fixed. Do not report security issues in public GitHub issues.

## What happens next

We acknowledge your report, assess it and track a fix.

## Not covered

We do not run a bug bounty programme today.
